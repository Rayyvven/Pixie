# Pixie
Pixie is a work in progress rhythm mobile game, which includes a built in level editor, custom music, and more! It is being solo-developed by Tobylerone, and has an extensive backlog of planned features.
## Planned Features:
- Level browser, sharing, exporting and importing
- Collectables, shops, perhaps a multiplayer currency
- Multiplayer, leaderboards, a friends system and messaging
- And more!
## Ways you can help:
- Playtest the game, download and play it.
- Join the Discord, where I post frequent updates: https://discord.gg/gF7gEj2BrH
- Visit the YouTube, where I post weekly Devlogs: https://www.youtube.com/@TobyLeroneNoCocoa
## Current Progress
The game began work on April 16th, and thus far has introduced many promised features, such as a level editor. Although it is still in very early stages, as a full-fledged release is set for 2027+.

## How to Install
### For Windows:
Visit https://github.com/Rayyvven/Pixie/releases and download the latest .exe and .pck.
The console is **not required**, but it may be helpful if you plan on assisting in development of Pixie.
### For Android:
Visit https://github.com/Rayyvven/Pixie/releases and download the latest .apk file
The .idsig and .pck files are **not required**.
