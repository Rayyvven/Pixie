# Pixie
Pixie is a work in progress rhythm mobile game, which will include a built in level editor, custom music, and more! It is being solo-developed by "Tobylerone" or "Ray", and has an extensive backlog of planned features.
## Planned Features:
- A fully fledged level editor
- Level browser, sharing, exporting and importing
- Custom song support
- The basic "Tiles"-esque game, with tiles such as the simple Tile, Hold Tile, Flick Tile, and more!
- Collectables, shops, perhaps a multiplayer currency
- Multiplayer, leaderboards, a friends system
- And more!
