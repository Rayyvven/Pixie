# Pixie
**Pixie** is a rhythm tile game actively being developed. The game includes a **built-in track editor**, in which you can upload **custom music**. The game is currently being solo-developed by **TobyLerone**, however any help is greatly appreciated. The game takes inspiration from games such as **Piano Tiles**, **Geometry Dash**, and **Osu!**, and will implement features from each game that are found to be useful. While many mobile games have the rhythm game element, almost no mobile rhythm games have editors of their own. Pixie is intended to be **community driven**, with as much of a focus on the editor as possible.

## Features:
- Track editor
- Track exporting & importing
- Custom music uploading

## Planned Features:
- Online track browser
- Collectables, shops, perhaps a multiplayer currency
- Multiplayer, leaderboards, a friends system and messaging
- And more!

## How to Install
### For Windows:
Visit https://github.com/Rayyvven/Pixie/releases and download the **latest .exe and .pck.**
The console is **not required**, but it may be helpful if you plan on assisting in development of Pixie.
### For Android:
Visit https://github.com/Rayyvven/Pixie/releases and download the latest .apk file
The .idsig and .pck files are **not required**.
